SAEKO Connector

Integración Odoo 19 ⇄ SAEKO para universidades: conexión segura, bitácora completa y datos crudos auditables.

🔐 Conexión OAuth2 / JWT

Service Account con llave RSA (RS256), delegación en un usuario del dominio, renovación automática del token y prueba de conexión paso a paso. Importe el bloque service_account tal como lo entrega SAEKO.

📜 Bitácora inmutable

Cada llamada HTTP: URL, parámetros, cuerpos y headers con secretos enmascarados, código, duración y error. Se escribe aparte de la transacción: sobrevive a fallos y rollbacks.

🗄️ Datos crudos versionados

El JSON tal como llegó, con huella SHA-256, versión, historial de cambios y detección de registros que dejaron de existir en SAEKO.

⏱️ Crons programables

Frecuencia por recurso (planteles, ciclos, programas, grupos, cursos, alumnos, profesores, becas…), healthcheck del token, aviso de vencimiento de la llave y depuración por retención.

🧩 Endpoints como datos

Rutas, dependencias padre→hijo, paginación y detalle por ID se configuran desde la interfaz. Un endpoint nuevo de SAEKO no requiere programar.

🔎 Explorador API

Lance consultas GET de solo lectura, vea la respuesta y la estructura de campos detectada antes de dar de alta un recurso.

Cómo empezar

  1. SAEKO → Configuración → Conexiones → Nuevo.
  2. Importar Service Account e indicar el correo del usuario delegado.
  3. Probar conexión.
  4. En Recursos y programación, ejecutar ▶ cada recurso y revisar Datos crudos.
  5. Activar Sincronización automática.
